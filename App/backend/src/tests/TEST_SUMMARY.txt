================================================================================
ADDING NEW TESTS
================================================================================

When adding new endpoints:

1. Create test class in appropriate file
2. Follow naming convention: TestEndpointName
3. Include tests for:
   ✓ Success scenario
   ✓ Auth error (unauthorized)
   ✓ Validation error (invalid input)
   ✓ Not found error
   ✓ Edge cases

Example:
   class TestNewEndpoint:
       def test_success(self, client, auth_token):
           response = client.post("/new", params={"auth_token": auth_token})
           assert response.status_code == 200

       def test_unauthorized(self, client):
           response = client.post("/new")
           assert response.status_code == 401

       def test_invalid_input(self, client, auth_token):
           response = client.post("/new", params={"auth_token": auth_token}, json={})
           assert response.status_code == 400
